# 1묶음: 주변 감지·차량 정지와 복구

2026-11-05. 기본 integrated에 두 2D LiDAR와 측정 기반 보호 영역을 연결했다. 경로 계획·팔레트 인식은 다음 묶음이다. 실행은 루트 `Start.bat` → Unreal Editor에서 Play다. 웹에도 Unreal이 보낸 스캔·정지 상태·CSV를 표시한다.

## 측정과 판단

- 전방 좌측과 후방 우측에 각 270°·270개 광선, 10Hz, 범위 0.05~8m의 가상 센서를 둔다. 차체 좌표 장착점은 (+0.80,-0.57,-0.27)m와 (-0.80,+0.57,-0.27)m다. 평지의 광선 높이는 약 0.22m다.
- 실제 물리 충돌 형상의 가까운 표면을 측정한다. 용접된 팔레트 판재와 PhysicsOnly 형상도 포함한다. 장식용 QueryOnly/NoCollision 형상은 측정하지 않는다. 물체 이름이나 정답 위치를 정지 판단에 공급하지 않는다.
- 스캔당 동시 노출이며 회전 중 광선별 시간 차이는 모델링하지 않는다. 표준편차 3mm 잡음·1mm 양자화·50ms 전달 지연·패킷 누락·350ms 오래된 값 판정을 적용한다. 이는 실센서 사양이나 보정값이 아닌 가상 설계다.
- 유효 거리, 범위 내 반사 없음, 너무 가까움, 광선 누락, 차체 마스크를 구분한다. 웹은 유효하지 않은 거리를 null로 보내며 최대 거리로 채우지 않는다. 반사 없음은 장애물 부재의 보장이 아니다.
- 측정점을 장착점 기준으로 환산해 고정 보호 직사각형 x=-1.43~+2.70m, y=±1.30m 내부를 검사한다. 차체·포크 기준 외곽에 0.65m 여유를 둔 설정이다. 주변 점 그림은 차체 좌표이며 지도·위치 추정이 아니다.

## 조작과 정지 범위

| 입력·상태 | 동작 |
|---|---|
| 보호 영역 장애물 | 구동 명령 차단과 실제 휠 제동. 정차 상태에서 포크 승강은 허용 |
| LiDAR/필수 승강 센서 단절, 승강 고장, X | 주행·승강 정지를 래치. 유압은 중립·펌프 차단 |
| Y | 정상 신호가 0.3초 유지되고 이동·승강 입력이 중립일 때 복구 확인. 장애물이 있으면 주행 정지는 유지 |
| 장애물만 제거 | 자동 재출발하지 않음. 중립과 Y 필요 |
| Shift 유지 | 수동 팔레트 접근을 위해 장애물 주행 정지만 일시 해제. 목표 이동 속도 0.15m/s·각속도 0.15rad/s 제한. 고장·X 정지는 우회하지 않음 |
| Shift 해제 | 주행 정지 재적용. 정상 영역에서 중립·Y로 일반 주행 복귀 |
| U | 기존 관절·동역학·근거리 센서와 LiDAR 통신 중단/복구 주입 |
| I | LiDAR 광선 표시 전환 |

속도를 강제로 0으로 덮어쓰거나 차체를 고정하지 않는다. 유한 제동 토크와 유압 응답 때문에 정지 명령 뒤 실제 이동이 남는다. 전체 정지 복구 시 이전 포크 목표를 재개하지 않고 현재 **측정 높이**를 새 목표로 잡는다. 수동 저속 모드는 자동 삽입·충돌 회피가 아니며 사용자가 주변을 확인하며 조작하는 단계다.

## 설정·제약

`Config/LidarSafety.json`에서 주기·범위·장착점·보호 영역·지연·잡음·일반 속도 제한(1m/s, 0.6rad/s)을 설정한다. 고정 높이의 2D 평면 밖에 있는 물체는 놓칠 수 있고 포크·낮은 적재물·경사면이 광선을 가로막으면 보수적으로 정지할 수 있다. 적재물 인식으로 자체 물체를 임의 삭제하지 않는다.

이번 정지 시험은 평지·기본 마찰의 지정 장애물과 적재 조건이다. 저마찰·경사로·모든 적재 상태의 정지거리, 속도별 가변 보호 영역, 안전 등급을 보장하지 않는다. 기존 주행 제어에는 물리 정답 속도/회전 보정이 남아 있다. 엔코더·IMU 제어, 위치 추정과 주행 명령 watchdog은 후속이다. 기존 유압 명령 watchdog은 유지한다. 새 FPS 성능 검증이나 실차 보정을 완료한 것으로 표시하지 않는다.

## 검증

`Scripts/Test-LidarSafety.ps1`은 전·후·측면·대각선, 수동 저속 접근, 스캔 단절, 비상정지, 적재 운반, 30FPS 전방 조건과 기존 운반·경사 제동을 실행한다. 실제 스캔은 독립적인 알려진 시험 상자 교차 거리와 비교하고, 8m 밖 물체는 정상적인 반사 없음으로 검사한다. 이 정답은 시험 판정에만 사용한다. CSV는 정지 이후 속도, 정상 신호 복귀 뒤 래치, 확인 뒤 재개, 적재 높이 유지와 측정 주기를 확인한다.

초기 후보의 정지+0.8초 이후 0.1m/s 미만 기준은 제동·타이어의 감쇠하는 반동 때문에 실패했다. 이를 숨기거나 물성을 변경해 맞추지 않았다. 최종 검사는 제동+3초 이후 0.1m/s 미만과 장애물 외곽 여유를 별도로 확인하며, 초기 과도 속도도 결과에 남긴다. 따라서 즉시 정지나 짧은 정착 시간을 달성했다는 의미는 아니다. 수동 저속 모드가 끝난 뒤의 정착 구간은 별도 검사한다.

최종 Native 11조건(신규 보호 9조건·기존 물리 2조건)이 통과했다. 신규 시험의 장애물 외곽 최소 여유는 조건에 따라 약 0.340~0.508m였고, 정지+0.8~3초 과도 구간 최대 속도는 약 0.223m/s였다. Shift 수동 접근의 측정 최대 속도는 0.1383m/s였다. 실제 측정 주기는 약 10.004~10.011Hz였다. 이 수치는 지정 시험의 관측값이다.

최종 빌드의 단위 62/62와 기존 두 카메라의 실제 GPU 거리·near/far 결측·지연·RGB-D 동기 회귀가 통과했다. 웹 상태 관리와 관절/동역학/근거리/승강/LiDAR CSV 함수 회귀도 통과했다.

실제 웹 수신 302프레임에서 장애물 정지 64프레임, 장애물이 해소돼도 정지 유지 22프레임, 확인 후 주행 허용 6프레임과 18열·302행 CSV를 확인했다. 공유 측정점 투영/CSV 함수와 실제 수신을 검증했으며 브라우저 버튼 클릭을 자동화하지 않았다. 기존 운반·경사 제동은 이전 빌드와 9개 물리 CSV 항목의 최대 차이가 0이었다. 기존 물리 비교 경로는 보호 기능을 끈 역사적 시험 조건이다.
