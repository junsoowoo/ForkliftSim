# 0.11.1 — 접촉 수치 오차 보정과 적재 통합 검증

## 현재 판정

이 단계는 **가상 설계 사양의 정합성 검증**이다. 실제 지게차의 질량 분포·재질 실험·모터 곡선·유압 측정 데이터가 없으므로 실차 보정 완료라고 부르지 않는다. 실제 사양을 확보하기 전까지 타이어/노면 마찰이나 감쇠를 바꿔 수치 오차를 상쇄하지 않는다.

기존 행동 시험의 PASS와 새 정량 기준의 PASS를 구분한다. 특히 무동력 시험은 기존 허용 범위(최종 속도 1.8~2.1 m/s)를 통과해도, 새 속도/에너지 증가 1% 기준에는 실패할 수 있다. 실패한 항목을 숨기거나 허용 오차를 결과에 맞춰 넓히지 않는다.

## 0.11.1에서 바꾼 계산

- 바퀴 단독 구름 시험(`RollingReference`)을 추가했다. 차체·관절·모터·유압 없이 원통/구의 병진·회전·중력 에너지를 측정한다. 기존 원통은 약 10초 동안 감속하고, 기존 지게차는 가속하는 오차가 있었다. 구 기준물은 보존 시험을 통과했다.
- `ContactLoadSampler`의 물리 스레드 접촉 수정 단계에서 **등록된 박스형 노면의 면 내부**만 정확한 원통 반지름의 접촉점과 노면 법선으로 보정한다. 좌우 어깨 접촉점의 축 방향 위치를 유지해 횡하중·기울어짐을 없애지 않는다. 속도나 에너지 강제 보정, 마찰력 추가, 차체 방향 강제 설정은 하지 않는다.
- 박스 모서리 1 mm 이내, 비박스 지형, 일반 장애물, 거의 옆면으로 누운 타이어 접촉은 기존 Chaos 충돌 계산으로 남긴다. 기존 256분할 충돌체는 충돌 후보와 모서리 접촉 생성에 계속 사용한다. 고무 접촉 패치나 유한요소 해석이 아니다.
- UE 5.6의 접촉점 교체 API는 마찰 고정점 위치를 초기화하지만 `bHasStaticFrictionAnchor` 표시를 남긴다. 새로 투영한 점에서는 이를 해제하여 엔진의 접촉 속도 기반 마찰 경로를 사용한다. 이를 빠뜨리면 무동력 보존만 좋아지고 구동·제동 전달력이 사라지므로 선회·제동·저마찰 회귀를 함께 검사한다. 정지/운동 마찰계수는 유지한다.
- 바퀴 하중의 **내부 스텝 최대/최소**와 기존 **프레임 평균의 최대/최소**를 분리했다. `INTEGRATED_INNER_LOAD`, CSV `integrated_inner_peak_wheel_n/min_wheel_n`이 새 지표다. 충격 피크의 시간 간격 수렴은 별도 판정해야 한다.
- 유압 압력/입력 전력 피크와 릴리프 배출량도 내부 스텝에서 누적한다. 양중 속도는 0.25~0.55 m 구간을 경계 프레임까지 보간하여 실제 이동거리/통과 시간으로 계산한다. 마지막 내부 스텝 속도 하나를 프레임 전체 속도로 간주하던 표본 오차를 줄였다. 유압 ODE·질량·마찰·모터 사양은 이번에 변경하지 않았다.
- 적재 경사 시험의 최대 실행 시간을 64→80초로 늘렸다. 인위적인 접촉 추진이 사라진 상태에서 하강 후 평지 제동까지 관측하기 위한 시간 확보이며, 경사 통과 거리·정지거리·속도·화물 안정 판정은 완화하지 않았다. 정상 대기 시간과 제동 시작 위치도 별도 변수로 분리했다.

이 보정은 현재 4륜 독립 조향 모델에 기본 적용된다. `-LegacyTyreContacts`는 이전 접촉과 A/B 비교하는 진단 옵션이며, 사용자 JSON을 변경하지 않는다. `NUMERICAL_CONTACT refined=...`로 실제 보정 적용 횟수를 확인한다.

## 실행

프로젝트 루트의 Windows PowerShell 5.1에서 실행한다. 먼저 `Scripts/Build.ps1`로 빌드한다.

```powershell
# 4가지 기준 시험 × FPS 2종 × 물리 간격 2종. 실패해도 나머지 결과 수집.
.\Scripts\Test-PhysicsCalibration.ps1
# 단일 바퀴: 전진/후진, 원통/구, FPS와 물리 간격 비교
.\Scripts\Test-RollingReference.ps1
# 이전 접촉 계산 재현 (엄격 판정 실패가 예상되는 진단)
.\Scripts\Test-PhysicsCalibration.ps1 -Fps 60 -PhysicsHz 480 -Cases coast_none -LegacyTyreContacts
# 적재 통합 7종
.\Scripts\Test-IntegratedPhysics.ps1
# 다른 계산 간격의 같은 통합 시험
.\Scripts\Test-IntegratedPhysics.ps1 -Fps 30 -PhysicsHz 240
# 조향 모터를 끈 진단 (기본 물성/일반 주행을 변경하지 않음)
.\Scripts\Test-PhysicsCalibration.ps1 -Fps 60 -PhysicsHz 480 -Cases coast_none -PassiveSteer
# Unreal 재실행 없이 기존 보고서 재판정
.\Scripts\Compare-PhysicsCalibration.ps1 -ReportDirectory .\Saved\Validation\Calibration-실행시각
# PS 5.1의 JSON 배열·실패 판정 회귀 검사 (합성 데이터, 물리 시험 아님)
.\Scripts\Test-ValidationReports.ps1
```

보고서는 `Saved/Validation/Calibration-*`와 `Integrated-*` 아래 `manifest.json`, `results.json`, 로그에 저장한다. 계산 간격 비교는 `timestep-comparison.json`이다. 실패 시 스크립트는 0이 아닌 종료 코드를 반환한다. 엔진 종료 코드뿐 아니라 명시적 시험 PASS도 확인한다. 동작 CSV는 기존 `Saved/Telemetry/Stability-*.csv`를 유지한다.

### 오차 기준

- 평지 정지: 네 바퀴 하중 합과 `m*g`의 상대 오차 <3%, 앞뒤·좌우 하중 비율은 COM 모멘트 기준과 차이 <0.03. 경사·충격 중의 법선력 합을 `m*g`에 억지로 맞추지 않는다.
- 타이어: 정지 관절 지지력과 `K*눌림`의 오차 <6%. 바퀴/링 자체 중량과 차체 지지력은 구분한다.
- 유압: 일정 상승 구간에서 `P*효율 = (m*g + 씰 저항 + 점성 저항*v)*v` 기준 속도와 오차 <5%. 시작·접촉·정지 구간은 제외한다.
- 무저항 관성 주행: 초기 속도 주입 후 2.1초부터 끝까지 속도 변화 <1%, 에너지 증가 <초기 차체계 병진 운동에너지의 1%. 중력 위치 에너지의 임의 기준 높이로 나눠 오차를 작게 보이지 않는다.
- FPS/물리 간격에 따른 주요 정량 지표의 변동 <3%. `NUMERICAL_STEP`으로 실제 콜백에서 사용한 최대 내부 간격과 GT 간격도 검사한다.
- 에너지는 차체·포크·모듈·타이어의 병진/회전/중력, 타이어 스프링, 유압 축적분을 포함한다. 이번에 누락됐던 팔레트·화물의 강체 에너지도 추가했다. 일반 동력 주행의 완전한 에너지 수지는 아니다. 조향 전력·모든 충격 마찰 소산까지 모델링했다는 뜻이 아니다.

## 적재 노면 시험

자동 입력은 재현 가능한 **시험 절차**이며 센서/자율 주행 기능이 아니다.

- 팔레트와 화물을 고정하지 않고 실제 포크–구멍–팔레트–화물 접촉으로 양중한다. 자동 시험은 삽입 깊이 1.1 m에서 시작하며 삽입 과정 자체는 기존 cargo_entry 시험의 범위다.
- 포크 높이 목표 .45 m, 10초까지 평지에서 양중·유지·정하중 비교 후 출발한다. 수동 시작은 원래처럼 직접 삽입해야 한다.
- 적재 경사는 X=6~14 m, 턱은 X=7 m부터다. 기존 무적재 시험장보다 3 m 뒤로 이동해 초기 팔레트가 지형과 겹치지 않는다.
- `flat`: 평지 운반 후 제동.
- `ramp`: 6도 오르막 → 정상에서 정지 → 후진 내리막 → 평지 제동. 경사 양방향 통과를 위치/속도/기울기로 확인한다.
- `step`: 25 mm 전체 폭 턱 통과 후 제동.
- `halfstep`: 왼쪽 바퀴만 25 mm 높이로 올라가는 노면. 좌우 실제 바퀴 높이 차이 >15 mm를 확인한다.
- `split`: 왼쪽 μ=.08 / 오른쪽 μ=.8에서 운반·제동. 실제 접촉 재질 값도 확인한다.
- `ramp_eccentric`, `step_eccentric`: 화물 COM을 오른쪽으로 12 cm 이동한 동일 시험.

화물의 지지 상실/전도/낙하 없음, 팔레트/화물 이동 <5 cm, 타이어 스트로크 바닥침 없음, 최종 속도 <.03 m/s, 제동거리 <.6 m, 모터/유압 한계를 검사한다. 이는 이 저속·저상 조건의 회귀 기준이지 실제 운반 안전 정격이 아니다. 순간 최소/최대 바퀴 하중과 미끄럼은 클리핑하지 않고 기록한다.

## 0.11.0에서 확인된 오차 (수정 전 기록)

무저항 coast에서 약 10초 동안 속도와 에너지가 증가한다. 조향 구동을 꺼도 발생하며, 유압을 과거 서보로 바꾸거나 타이어 수직 탄성을 꺼도 남는다. 충돌면 분할 증가, 더 작은 시간 간격, 반복 횟수 증가, 접촉 shock propagation 제외, 위치 마찰 대신 속도 마찰 사용만으로는 해결되지 않았다. 따라서 유압/조향 모터만의 문제라고 단정하지 않으며, 접촉 형상·회전 관절·솔버 조합을 더 작은 벤치로 분리하는 것이 후속 원인 분석이다.

이전 오차가 남은 상태에서는 1 Nm 수준의 베어링 저항이나 저속 구름저항을 실측에 맞췄다고 발표할 수 없었다. 0.11.1의 변경은 위 접촉 보정이며, 기본 마찰/저항/질량을 조정하거나 매 프레임 속도/에너지를 강제로 깎은 것이 아니다. 앞으로도 작은 손실의 분해, 모서리 충격, 유압 에너지 수지, 실제 물성값 보정에는 별도 검증이 필요하다.
