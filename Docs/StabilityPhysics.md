# 3D 지게차 접촉·슬립·전복 시험장

> 이 문서는 이전 0.3 뒷바퀴 조향 구조의 기록입니다. 현재 기본 실행은 [0.4 독립 조향·구동](SwerveDrive.md)입니다.

`Start-StabilityLab.bat`로 실행합니다. `Config/Vehicle3D.json`이 설정 파일입니다.
Unreal 5.6.1 / Chaos 강체·접촉·관절을 사용합니다. 기존 평면 주행 모델과 별도입니다.
현재 0.3.1은 조향 시 차체–타이어 내부 충돌로 정지하던 문제를 수정한 버전입니다.
`Start-RolloverDemo.bat`를 실행하면 고중심 급조향 시험을 화면으로 재생하고 12초 뒤 종료합니다.
이 데모는 마찰계수 1.5 / 1.5, 무게중심 +1.2 m, 초기 속도 8 m/s, 조향 120 deg/s를 사용합니다.

## 구성

```text
StabilityLab (시험·입력·기록 관리, 물리 몸체 없음)
 ├─ ChassisActor: 차체 + 용접한 마스트·밸러스트, 하나의 강체
 ├─ WheelActor FL / FR / RL / RR: 각각 독립 액터
 │   ├─ Knuckle: 차체와 조향 관절로 연결, 앞은 고정 / 뒤는 조향
 │   └─ Tyre: 너클과 회전축 관절로 연결, 바닥과 직접 충돌
 └─ ForkActor: 캐리지 + 두 포크를 용접한 강체, 차체와 수직 가이드 연결
```

질량은 차체 1,800 kg(마스트·밸러스트 포함), 포크 150 kg, 바퀴 각 50 kg, 너클 각 5 kg으로 합계
2,170 kg입니다. 화면용 바퀴 무늬와 빨간 차체 무게중심 표시는 질량·충돌에 기여하지 않습니다.
너클은 0.2 m 크기의 비충돌 관성 형상입니다. 차체/포크는 상자입니다. 타이어 렌더링은 엔진
실린더를 사용하고, 타이어 충돌은 각 컴포넌트의 128각형 원통 볼록 형상을 사용합니다.
기존 엔진 실린더 충돌은 둘레 32각형이라 저속 구름의 각진 면 효과가 컸습니다.
엔진 원본 에셋은 변경하지 않습니다. 바퀴와 포크를 매 프레임 위치 지정해서 움직이지 않습니다.

같은 차량의 차체–타이어 충돌은 제외합니다. 단순 상자 차체에는 실제 장비의 휠하우스가 없어서
조향한 타이어가 차체 상자에 끼는 문제가 있었습니다. 모든 축이 자유인 추가 관절은 이 두 강체의
충돌 필터만 지정하며 위치·회전 제한·구동력은 가하지 않습니다. 바닥·외부 장애물과의 충돌은 유지합니다.

차체의 높이·롤·피치는 자유롭습니다. 관절이 부품끼리 연결하고 바닥 접촉이 차량을 지지합니다.
앞바퀴 두 개에 토크를 적용하며 모터 반력은 차체에 반대로 적용합니다. 뒤는 Ackermann
목표각으로 조향합니다. 뒷바퀴 조향 관절의 기계적 상한은 ±55도이며, 안쪽 바퀴는 기준 조향각보다 더 꺾입니다.

## 조작

| 키 | 동작 |
|---|---|
| W / S | 전진 / 후진 구동 토크 |
| A / D | 좌 / 우 회전 명령, 실제 조향은 뒷바퀴 |
| Space | 네 바퀴 제동 |
| Q / E | 포크 목표 높이 하강 / 상승 |
| 1 / 2 | 타이어 마찰계수 -0.1 / +0.1 |
| 3 / 4 | 노면 마찰계수 -0.1 / +0.1 |
| F | 노면 마찰 0.8 ↔ 0.08 비교 전환, 차량 리셋 없음 |
| R | 현재 설정으로 차량 재생성, 이전 기록 저장 |
| G | 기본 설정 ↔ 높은 무게중심 시험 설정, 차량 재생성 |

마찰계수는 0~2 범위입니다. 윗줄 숫자와 숫자패드(Num Lock 켜짐)를 지원하고 누르고 있으면
반복 변경합니다. 화면에 변경 전/후 값과 접촉 마찰을 4초 동안 표시하며 어느 재질이 한계를
정하는지도 표시합니다. 변경 즉시 물리 재질에 적용합니다. 마찰은 접지 한계이므로 작은 변경이
항상 직진 속도 차이로 나타나지는 않습니다. F로 큰 차이를 비교할 수 있습니다.
G는 무게중심 오프셋 +1.2 m, 모터 무부하 속도 8 m/s, 조향 속도 120 deg/s,
최대 기준 조향각 35도로 바꿉니다. 마찰값은 유지합니다. G를 다시 누르면 JSON의 속도·조향·무게중심
설정으로 돌아갑니다. 차체 질량의 60%를 밸러스트로 모델링하고, 오프셋 h를 주면 이를 h/0.6만큼
위로 이동시킵니다. 따라서 차체 무게중심이 h만큼 높아지고 회전관성도 질량 배치로부터 계산됩니다.
기본 상태의 밸러스트는 차체 안에 있으며, 높이 올리면 파란 상자로 보입니다.
이것은 시험용 질량 배치이며, 포크에 실제 화물을 적재한 것과 다릅니다.
빨간 구는 차체 강체의 무게중심입니다. 전체 차량 무게중심과는 다릅니다.

## 설정과 단위

| 설정 | 기본값 | 의미 |
|---|---:|---|
| chassis_mass_kg / wheel_mass_kg / knuckle_mass_kg / fork_mass_kg | 1800 / 50 / 5 / 150 | 각각의 질량, 바퀴·너클은 한 개 기준 |
| wheel_radius_m / wheel_width_m | 0.30 / 0.18 | 바퀴 반경·폭 |
| wheelbase_m / track_m | 1.60 / 1.30 | 앞뒤 축간거리·좌우 바퀴 중심 간격 |
| tyre_friction / road_friction | 0.9 / 0.8 | 접촉 재질의 마찰 입력 |
| drive_torque_nm / brake_torque_nm | 450 / 900 | 구동 바퀴별 최대 토크·바퀴별 제동 토크 상한 |
| max_speed_mps | 3.0 | 모터 토크가 0이 되는 무부하 바퀴 둘레 속도, 차체 속도 강제 제한 아님 |
| max_steer_deg / steer_rate_deg_s | 30 / 30 | 기준 조향각·명령 변화율 상한 |
| steering_torque_limit_nm | 5000 | 뒷바퀴별 조향 관절 구동 토크 상한 |
| chassis_com_offset_m | 0.0 | 차체 전체의 자동 계산 무게중심에서 위쪽으로 이동하는 거리 |
| fork_travel_m / fork_speed_mps / fork_force_limit_n | 1.5 / 0.25 / 15000 | 포크 이동 범위·목표 변화 속도·구동력 상한 |

코드와 CSV는 m, s, kg, N, Nm, rad/s를 사용합니다. 화면에서 차체 기울기와 조향은 degree로
표시합니다. 엔진 적용 시 N → kg·cm/s²는 ×100, Nm → kg·cm²/s²는 ×10000으로 변환합니다.
바퀴 관성은 질량과 충돌 형상으로 계산됩니다. 독립적인 회전관성 설정은 아직 없습니다.

구동 토크는 바퀴 회전 속도가 무부하 속도에 가까워질수록 선형 감소합니다. 바퀴 각속도는
차체 속도로 덮어쓰지 않으므로 공회전·종슬립이 가능합니다. 제동은 상대 회전을 감쇠하는
관절 모터이며 지정 토크 상한을 둡니다. 저항은 강체의 작은 선형·각 감쇠와 접촉 손실이며,
별도의 실측 구름저항·모터·유압 모델은 아직 없습니다.

포크는 힘 제한이 있는 위치 스프링/감쇠기로 움직입니다. 목표 속도는 제한하지만 실제 속도·가속도는
질량·중력·구동력·접촉에 따라 결정됩니다. 이전 정지식 승강 시험장의 센서·PI 제어기는 아직 이식하지 않았습니다.

## 마찰과 전복의 의미

타이어와 노면의 Physical Material 모두 `Min` 결합 규칙을 지정했습니다.
`유효 μ = min(타이어 μ, 노면 μ)`이며 정지·운동 마찰에는 같은 입력을 사용합니다.
예: 타이어 0.9, 노면 0.2이면 접촉에 0.2를 적용합니다. 이것은 엔진에서 선택한 간단한 재질
결합 규칙입니다. 현실의 고무·콘크리트 마찰을 두 독립 상수의 최솟값으로 예측할 수 있다는 뜻은 아닙니다.
[Epic Physical Materials Reference](https://dev.epicgames.com/documentation/unreal-engine/physical-materials-reference-for-unreal-engine)

마찰력이 부족하면 옆으로 미끄러져 회전 반응이 작아질 수 있습니다. 충분한 접지와 높은
무게중심에서는 바퀴가 들리거나 넘어질 수 있습니다. 강체의 무게중심·접촉·관절이 이 반응을
계산하며, 기울기 조건을 검사해서 차체를 넘어뜨리는 기능은 없습니다.
[OSHA 주행·조향 설명](https://www.osha.gov/etools/powered-industrial-trucks/operating-forklift/traveling-maneuvering)

3D 시험장은 4점 지지·강체 차축의 단순화 모델입니다. 실제 지게차의 후륜 요동 차축과
안정 삼각형, 타이어 탄성·하중에 따른 마찰 변화·유압·마스트 굽힘은 구현하지 않았습니다.
제조사 도면·타이어 실험·실차와 대조하기 전에는 실제 장비의 안전 속도·전복 한계로 해석할 수 없습니다.
[OSHA 무게중심·안정성 설명](https://www.osha.gov/etools/powered-industrial-trucks/load-handling/load-composition)

## 기록과 검증

화면/CSV의 속도·자세는 센서가 아닌 엔진 물리 상태입니다. 가속도는 매 프레임 속도 차분으로
구해 접촉 충격과 초기조건 주입 시 큰 순간값이 나올 수 있습니다. 횡슬립은 타이어 하단의 근사
접촉점 속도를 바퀴 좌우 방향에 투영한 값입니다. 종슬립은 같은 점의 앞뒤 속도 부호를 뒤집은 값입니다.
바퀴가 크게 기울면 실제 접촉점과 차이가 커집니다. 공중에 있는 바퀴의 값은 지면 슬립으로 읽지 않습니다.
`Near-floor wheels`는 평평한 바닥과의 기하학적 간격으로 판단한 근사치이며 접촉력 센서가 아닙니다.

`Saved/Telemetry/Stability-*.csv`에 마찰·무게중심 설정, 차체 속도·가속도·회전 속도·롤/피치,
바퀴별 종/횡슬립·각속도·토크 명령·제동 상한·실제 조향각·바닥 간격, 포크 목표/실제 높이를 저장합니다.
실제 타이어 접촉력과 실제 유압력은 아직 별도 계측하지 않습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Scripts\Test-Stability.ps1
# 화면 갱신 주기에 따른 영향 확인:
powershell -NoProfile -ExecutionPolicy Bypass -File .\Scripts\Test-Stability.ps1 -Fps 60
```

시험은 2초 정지 후 진행합니다. 조향·제동 비교는 모든 강체에 같은 초기 병진 속도를 한 번
설정하고, 바퀴 각속도도 구름 상태로 맞춥니다. 이후 위치·자세·속도를 덮어쓰지 않습니다.
이 초기조건 주입은 자동 운전 기능이 아닙니다. 정지·직진·무마찰 공회전·제동·승강·급조향·
저마찰 노면·저마찰 타이어·전복을 확인하며, 비정상 속도/회전 속도에도 실패하도록 구성했습니다.
0.3.1에는 W+D/W+A 지속 추진 선회, 저마찰 추진 선회, 주행 중 마찰 해제·복원,
윗줄/숫자패드 키 바인딩 및 물리 재질 읽기값 검사도 추가했습니다.
접촉 해결용 질량·관성 자동 보정과 관절 투영을 끄고 강체의 형상/질량을 사용합니다.
기본 물리 서브스텝은 최대 1/120초이며 30/60/120 fps 시험도 별도로 비교해야 합니다.

현재 검증은 [DriveFixValidation.md](DriveFixValidation.md), 이전 0.3.0 기록은
[StabilityValidation.md](StabilityValidation.md)에 있습니다.
