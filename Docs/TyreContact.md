# 타이어 모서리 접촉과 실제 접촉점 하중
0.14.0에 [선택형 분할 트레드 모델](DiscreteTread.md)을 추가했다. 이 문서의 원형 투영은 기존 기본 타이어에서 유지한다. 조각별 하중 집계는 분할 트레드에도 확장했고, 그 형상에는 원형 투영을 적용하지 않는다.

0.13.1은 강체 외피의 접촉 기하와 계측을 개선한다. 0.13의 비선형 수직·전단 관절 탄성을 유지하며, 접촉력을 추가로 가하지 않는다.

## 적용 범위

- 평면 내부: 기존 매끄러운 원통 접촉을 유지한다.
- 타이어 축과 평행한 박스 모서리: 원형 단면과 선분 모서리의 최근접 위치·법선을 계산해 기존 Chaos 접촉점에 반영한다. 원형 반지름, 축 방향 어깨 위치와 관통 깊이를 보존한다.
- 비평행 모서리, 박스 꼭짓점, 휠 측면, 비박스 지형: 기존 Chaos 충돌 계산을 사용한다.
- 평행 판정은 축·모서리 단위벡터 내적 절댓값 0.99999 이상으로 제한한다. 정확히 평행할 때 원 방정식과 일치하며, 허용 오차 내의 미세한 기울기는 근사다. 모서리 접촉점은 실제 박스 모서리에 고정한다.
- 기존 충돌 후보만 수정한다. 새로운 접촉점을 인위적으로 생성하거나 접지력을 가산하지 않는다. 정지 제동의 마찰 앵커 보존도 유지한다.

기본 상세 프로필에서 적용한다. `-NativeTyreEdges`는 모서리 보정만 끈 비교 시험 옵션이다. `-ReferencePhysics`의 동결 V1 모델은 상세 타이어가 꺼져 있어 기존 모서리 계산을 유지한다.

## 웹과 CSV의 측정 정의

물리 내부 스텝에서 유효 접촉점의 법선 충격량 `Jn`을 수집한다. 위치와 반력은 Chaos 솔버의 값이다.

- 접촉점 법선 하중 합: `ΣJn / 측정 구간 시간`.
- 폭 방향 3구간: 휠 축의 음수 쪽 1/3, 중앙 1/3, 양수 쪽 1/3으로 접촉점을 분류한다. 각 구간 하중의 합은 접촉점 하중 합과 같아야 한다. 좌우 구간은 타이어의 축 좌표 기준이며 차체 좌/우 이름과 혼동하지 않는다.
- 접촉 하중 중심: `Σ(Jn × 위치) / ΣJn`. 서로 다른 면이 동시에 닿을 때 단일 평면의 압력중심과 같다고 해석하지 않는다.
- 법선력 모멘트: 휠 중심에 대한 `Σ((접촉 위치 − 휠 중심) × 법선 충격량) / 시간`.
- 최대 동시 접촉점: 측정 구간 내 단일 내부 물리 스텝에서 지지 충격량이 발생한 접촉점 수의 최댓값이다. 기존 `contact_events`는 구간 전체의 접촉 쌍 누계여서 같은 지표가 아니다.
- 접촉이 없으면 웹 하중 중심은 `null`이다. CSV는 `contact_center_valid=0`이며 자리 채움 좌표를 유효한 측정으로 해석하면 안 된다.

웹의 `wheels[].solver_contact`가 원본이며, 기존 바퀴 하중은 접촉 쌍 단위 집계도 유지한다. `point_vs_pair_peak_n`으로 두 집계의 최대 차이를 진단한다. 면적을 가정해 이산 접촉점 힘을 실제 면압으로 바꾸지 않는다. 기존 `estimated_patch_length_m`, `estimated_peak_pressure_pa`는 구성식·기하 추정치다.
강체 원통은 양쪽 어깨의 이산 접촉점에 반력이 집중될 수 있다. 중앙 구간이 0이라고 실제 고무 타이어의 중앙 면압이 0이라는 뜻은 아니다. 이 차이가 외피 변형·유한 접촉 면적 모델을 추가해야 하는 이유다.

## 실행

일반 사용은 `Start.bat` → Play다. T로 전체 턱/한쪽 턱을 선택하고 낮게 양중해 운반한다. 웹을 새로고침하면 바퀴 카드에 실제 접촉점·폭 방향 하중·세계 좌표 하중 중심이 표시된다.

```powershell
# 기본 하이브리드 장비, 425 kg 적재, 25 mm 턱
./Scripts/Test-Components.ps1 -Cases step,halfstep -Fps 60
# 모서리 보정 전후 비교
./Scripts/Test-Components.ps1 -Cases step,halfstep -Fps 60 -NativeTyreEdges
# 실제 Unreal 프레임을 웹에 보내며 시험
./Scripts/Test-Components.ps1 -Cases halfstep -Fps 30 -WebTelemetryUrl http://127.0.0.1:4173/api/telemetry
node Web/PhysicsLab/verify-components.mjs
```

시험은 실제 팔레트·자유 화물을 들어 올린 뒤 턱을 통과하고 정지한다. 화물 지지 손실·전도·타이어 스트로크 초과·접촉점 집계 오류를 확인한다. 기하 단위 시험은 다양한 반지름·접촉 각도·침투/이격 조건을 독립적인 원 방정식과 비교하며 하중·모멘트 평형도 확인한다.

## 남은 범위

외피는 여전히 단단한 링이다. 실제 고무 메시 변형, 유한 접촉 면적의 압력 분포, 턱을 감싸는 재료 변형은 구현하지 않았다. 보정된 모서리 접촉을 실제 타이어의 턱 감싸기나 FEM 해석으로 소개하면 안 된다. 이번 계측은 향후 외피 분할 모델과 현재 강체 모델을 비교할 기반이다. 새로운 실차 물성 측정값을 확보한 작업도 아니다.
