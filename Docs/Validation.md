위 시간은 **시뮬레이션 시간**이다. 팔레트 최대 수평 이동은 baseline에서 약 0.0001 m였다.
DX11에서 RTX 3050 Laptop GPU를 사용하는 실제 렌더링도 확인했다. `LiftLab.png`는
18초 시점의 HOLDING 상태를 캡처한 이미지이며 작은 뷰포트에서도 계기판이 표시된다.
기본 조건의 실제 합성 강체 질량은 캐리지+포크 100.000 kg, 팔레트+화물 275.000 kg으로
설정값과 일치한다. 포크가 삽입구 안에서 빈 공간 약 0.2 m를 올라간 다음 상판에 접촉하므로,
포크 목표 상승 0.65 m와 팔레트 상승 약 0.45 m는 다르다.

## 개발 중 검출하고 수정한 문제

1. 한글 상위 디렉터리에서 MSVC 응답 파일 경로 오류: 빌드 스크립트가 TEMP의 영문 junction을 사용.
2. 지연 센서에 비해 높은 속도 제어 이득으로 인한 진동: 위치/속도 제어 이득을 조정.
3. 용접 부품의 기본 질량 추가: 부품별 질량을 명시하고 `GetMass()`로 합계를 검증.
4. 힘 포화 경계에서 명령이 한계에 도달하지 않는 이산 적분 처리: 출력 포화 처리를 수정.

## 검증의 한계

- 이 결과는 시뮬레이터 내부 검증이며 실제 지게차와의 정합성 또는 안전 인증이 아니다.
- 현재 기본 질량 조건과 명시된 고장 시나리오만 자동 검증했다. 모든 질량·마찰 조합이 검증된 것은 아니다.
- 시간 간격 수렴, 반복 리셋, 높은 위치의 적재 상태에서 센서 고장, 마찰별 횡방향 거동은 후속 검증 항목이다.
- 속도와 가속도 한계는 명령 제한이다. 실제 충돌 가속도 또는 승강 속도에 대한 하드 리밋이 아니다.
- 바퀴 주행, 조향, 전복, 자동 인식·삽입·운반은 아직 구현하지 않았다.

원시 로그와 CSV 및 설정 메타데이터는 로컬 `Saved/Logs`, `Saved/Telemetry`에 남으며 Git에는 넣지 않는다.
