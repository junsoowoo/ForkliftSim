# 1번 묶음 — 분리 서버 연결 확인

2026-11-05. 주변 LiDAR 감지·차량 정지/복구의 기존 구현을 ForkliftSim 전용 4174 포트에서 재검증했다. 새 기능이나 제동 물성 변경은 없다. 원래 기능과 제한은 [LidarSafety.md](LidarSafety.md)에 기록돼 있다.

- 기존 검증 DLL과 현재 DLL의 SHA-256이 일치함을 확인했다.
- Unreal 전방 장애물 시험을 30FPS 파라미터·960Hz 경량 물리·4174 전송으로 실행해 통과했다. 새로운 FPS 성능 벤치마크를 뜻하지 않는다.
- 실제 수신 325프레임, 장애물 정지 67프레임, 장애물 해소 후 정지 유지 23프레임, 확인 후 주행 허용 8프레임과 18열 CSV를 검증했다.
- 대시보드와 센서 모듈을 포함한 파일 10개의 실제 HTTP 200 응답을 확인했다. DOM 조작은 자동화하지 않았다.
- 전체 11조건을 다시 실행한 결과가 아니다. 이번에는 서버 분리의 영향을 받는 실제 전방 정지/복구·전송 경로를 확인했다. 제동 과도 운동 등 기존 제한은 유지된다.

실행은 루트 Start.bat → Play다. 현재 열려 있는 에디터의 송신 주소도 4174임을 확인했으며 에디터를 종료하거나 중복 실행하지 않았다. X 전체 비상정지, Y 정상 신호·입력 중립 시 복구 확인, I 광선 표시다. Shift는 수동 저속 접근을 위해 장애물 주행 정지를 일시 해제하며 고장·비상정지는 우회하지 않는다.
