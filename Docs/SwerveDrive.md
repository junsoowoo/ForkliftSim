# 0.4 — 4륜 독립 조향·구동 무인 지게차

`Start-StabilityLab.bat`를 실행합니다. 화면에 `0.4 / FOUR INDEPENDENT STEER + DRIVE`가 표시됩니다.
기존 창이 열려 있으면 닫고 다시 실행해야 새 빌드가 적용됩니다. 별도 설치나 에디터 설정은 필요 없습니다.

## 조작

| 키 | 동작 |
|---|---|
| W / S | 차체 기준 전진 / 후진 |
| A / D | 차체 중심 기준 좌 / 우 회전. 단독 입력하면 제자리 회전 |
| Z / C | 차체 방향을 유지하며 왼쪽 / 오른쪽 이동 |
| 조합 입력 | 이동과 회전 동시 수행. W+C는 사선 이동 |
| Space | 네 바퀴 제동 |
| Q / E | 포크 하강 / 상승 |
| V | 사선 / 상부 검사 시점 전환. 상부에서는 데크 외형만 숨겨 네 바퀴가 보임 |
| R | 현재 마찰 설정으로 장비 초기화 |
| 1 / 2 | 타이어 마찰 - / + 0.1, 숫자패드 지원 |
| 3 / 4 | 노면 마찰 - / + 0.1, 숫자패드 지원 |
| F | 노면 마찰 0.8 / 0.08 전환 |
| G | 고중심·고속 스트레스 설정 전환 후 초기화 |

큰 방향 변경에서는 네 바퀴를 먼저 정렬하므로 잠시 기다린 뒤 움직입니다. 화면의 `ALIGNING / drive paused`는
정렬 중, `READY / speed control`은 구동 가능한 상태입니다. 기본 조향 목표 변화율은
30 deg/s라서 정면에서 측면으로 정렬하는 데 약 3초가 필요합니다. 키를 놓으면 속도 제어가 정지를
목표로 하여 모터 토크로 감속합니다. Space는 별도의 900 Nm/바퀴 제동입니다.
청록색 화살표는 각 모듈의 **실제 정방향 축**입니다. 역구동하면 실제 이동 방향은 화살표 반대입니다.
상부 검사 시점에서도 차체 충돌·질량·관절은 그대로 적용됩니다. 표시만 숨깁니다.

## 물리 구성과 차체 공간

- 차체 1개, WheelActor 4개, 포크 1개. 각 바퀴 모듈은 조향 너클과 실제 회전 타이어 강체로 구성됩니다.
- 네 조향 관절의 수직축 회전을 허용하고, 각 바퀴에 독립적인 구동 토크를 적용합니다.
- 기본 바퀴 중심 위치는 앞뒤 ±0.8 m, 좌우 ±0.65 m입니다. 배치 범위를 좁히지 않고 외곽 차체를 넓혀 지지 폭을 유지했습니다.
- 바퀴의 조향 시 회전 범위 반경은 `sqrt(radius² + (width/2)²)`입니다. 기본 약 0.313 m입니다.
- 상부 데크는 약 2.426 × 2.126 × 0.22 m입니다. 데크 아래와 바퀴 상단 사이에 0.08 m의 공간이 있습니다.
- 중앙 하부 밸러스트 폭은 0.5 m이고 바퀴 회전 범위와 떨어져 있습니다. 마스트는 앞바퀴 회전 범위 앞쪽으로 옮겼습니다.
- 차체–타이어 충돌을 활성화했습니다. 이전 버전의 내부 충돌 제외 관절은 새 구조에서 사용하지 않습니다.
- 총 질량은 2,170 kg입니다. 차체·마스트·밸러스트 1,800 kg, 포크 150 kg, 타이어 각 50 kg, 너클 각 5 kg입니다.
- 타이어의 128각 원통 접촉, 마찰, 강체 관성, 구동 반작용, 중력, 바퀴 들림을 Chaos가 계산합니다.

## 제어

UE 좌표에서 X는 전방, Y는 오른쪽입니다. 중심으로부터 `(x, y)`에 있는 바퀴의 목표 접선 속도는
`(vx - yaw_rate * y, vy + yaw_rate * x)`입니다. 이 벡터에서 바퀴별 각도와 속도를 구합니다.
90도 넘게 꺾는 대신 타이어를 역구동하는 최적화를 적용합니다. 조향 명령은 변화율 제한을 통과합니다.

바퀴 방향이 목표와 크게 다르면 먼저 정렬합니다. 각 바퀴의 목표 속도와 측정된 둘레 속도의 차이에
비례하는 토크를 적용하고 450 Nm/바퀴로 제한합니다. 차체 방향 유지 피드백도 바퀴 목표에 반영됩니다.
차체 위치나 회전을 직접 지정하거나 차체를 강제 회전시키는 구동력을 추가하지 않습니다.

측정값은 현재 Chaos의 실제 상태를 직접 읽습니다. 센서 노이즈·샘플링·지연은 아직 구현하지 않았습니다.
목표 가속도 제한은 제어 명령에 적용되며, 충돌·접촉으로 생기는 실제 가속도의 상한을 보장하지 않습니다.

## 변경 가능한 설정

`Config/Vehicle3D.json`을 수정한 후 프로그램을 다시 실행합니다. 파일의 값은 실측 사양이 아닌 초기 설계값입니다.

| 설정 | 기본값 | 의미 |
|---|---:|---|
| drive_torque_nm | 450 | 각 바퀴의 구동/회생 감속 토크 상한. 네 바퀴에 적용 |
| brake_torque_nm | 900 | 각 바퀴 제동 토크 상한 |
| max_speed_mps | 3 | 바퀴 둘레 목표 속도 상한, 10.8 km/h |
| swerve_yaw_rate_deg_s | 45 | A/D 회전 목표 속도 |
| steer_rate_deg_s | 30 | 바퀴 조향 목표각 변화율 |
| steering_torque_limit_nm | 5000 | 각 조향 액추에이터 토크 상한 |
| swerve_acceleration_mps2 | 1.5 | 전후/좌우 속도 명령의 변화율 제한 |
| swerve_speed_gain_nm_per_mps | 350 | 바퀴 속도 오차 1 m/s당 토크 |
| tyre_friction / road_friction | 0.9 / 0.8 | 접촉 마찰은 두 값의 최솟값 |
| wheel_radius_m / wheel_width_m | 0.30 / 0.18 | 타이어 반지름 / 폭 |
| wheelbase_m / track_m | 1.60 / 1.30 | 바퀴 중심 사이 앞뒤 / 좌우 거리 |

`max_steer_deg`는 이전 뒷바퀴 조향 방식의 설정으로, 0.4 스워브 조향 범위를 제한하지 않습니다.
G는 실제 적재물을 올리는 기능이 아닌 높은 밸러스트의 스트레스 시험입니다.

## 검증 및 범위

측정 결과와 한계: [SwerveValidation.md](SwerveValidation.md).

`powershell -NoProfile -ExecutionPolicy Bypass -File .\Scripts\Test-Swerve.ps1`

새 구조의 정지, 전후진, 양쪽 횡이동, 양쪽 제자리 회전, 이동+회전, 주행 방향 전환, 무마찰,
저마찰, 제동, 포크 승강, 마찰 키 바인딩, 고중심 전복을 시험합니다. 일반 시험은 12초,
전진→횡이동→회전의 연속 전환 시험은 조향 시간을 포함해 18초입니다. 출력은 `Saved/Logs/Stability-swerve_*.log`,
물리 상태 기록은 `Saved/Telemetry/Stability-swerve_*.csv`에 저장됩니다.
바퀴별 목표각·실제각·목표속도·회전속도·토크·슬립·차체 접촉 횟수를 기록합니다.

`Scripts/Test-Stability.ps1` 기본 시나리오와 `Start-RolloverDemo.bat`는 비교용 **0.3 뒷바퀴 조향 구조**를 사용합니다.
기존 전복 시험의 통과를 새 0.4 장비의 검증으로 해석하면 안 됩니다.

새 `swerve_rollover`는 0.4 구조에서 마찰 1.5/1.5, 차체 무게중심 +1.2 m, 목표 최고속도 8 m/s,
회전 목표 90 deg/s, 조향 목표 변화율 120 deg/s를 사용합니다. 모터로 정지 상태에서 가속하고
6초부터 회전을 명령합니다. 전복은 접촉과 중력의 결과이며 초기 속도 주입이나 강제 회전은 없습니다.

새 구조는 평지용 초기 설계입니다. 현가장치, 실제 모터의 전기 특성·열·소비전력, 타이어 변형,
실제 지게차 사양 보정, 적재물과 센서·자동 운반은 후속 작업입니다.
