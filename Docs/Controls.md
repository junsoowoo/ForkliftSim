# 실행·배속·전체 단축키

기본 실행은 **Start.bat → Unreal Editor의 Play → 게임 화면 클릭**입니다. 웹에 키보드 포커스가 있으면 Unreal 단축키는 작동하지 않습니다. 창고와 기존 단일 장비 시험장은 키 배치가 다릅니다.

## 배속

| 키 | 동작 |
|---|---|
| F5 | 목표 1배 |
| F6 | 목표 2배 |
| F7 | 목표 4배 |

기본 창고와 `Start.bat -Map lab`에서 사용할 수 있습니다. 모든 차량·물리·센서·제어·작업 시간·배터리가 같은 월드 시계를 사용합니다. 키를 바꿔도 작업·시간·재고를 초기화하지 않습니다. 충전 에너지와 작업 KPI는 계속 시뮬레이션 시간을 기준으로 기록합니다.

시작부터 선택하려면 `./Start.bat -PlaybackRate 2` 또는 `./Start.bat -PlaybackRate 4`입니다. 옵션 없이 실행하면 기존 기본 속도를 사용합니다. 이전 정밀 타이어의 0.1~1배 저속 재생 옵션도 유지합니다. 1보다 큰 시작 값은 2·4만 허용합니다.

기본 제어 간격에서 2배는 최소 60 FPS, 4배는 최소 120 FPS까지 렌더 프레임 상한을 열어 요청 배속을 낼 여지를 줍니다. 1배 복귀·Play 종료 시 원래 상한을 복원합니다. 원래 무제한이었으면 무제한을 유지하고, 사용자가 별도로 상한을 바꿨다면 종료 시 그 변경을 덮어쓰지 않습니다. 프레임 상한을 높인다고 실제 PC가 그 속도를 낼 수 있다는 뜻은 아닙니다.

**목표 배속과 실제 진행은 다릅니다.** 화면과 웹에 두 값을 표시하고 계산이 밀리면 `PERFORMANCE LIMITED`/`계산 한계`를 표시합니다. 기존 최대 제어 간격 1/30초와 내부 물리 간격을 유지하므로, 이미 계산 한계인 PC에서는 목표를 4배로 올려도 실제 진행이 빨라지지 않을 수 있습니다. 계산 간격·센서 갱신·명령 유효시간을 늘려 숫자만 빠르게 만들지 않습니다.

이번 PC의 자연 시간 조건 4배 목표 시험에서는 실제 약 **0.65배**가 관측됐습니다. 6초의 짧은 시뮬레이션과 DX11 오프스크린 조건이며 Editor 평균 성능이나 실제 4배 진행을 보장하는 수치가 아닙니다. 실제 진행 표시는 실행 시작 이후 누적 비율이므로 배속 변경 직후에는 이전 구간도 포함합니다.

## 현재 창고 모드 — 기본 Start.bat

| 키 | 동작 |
|---|---|
| W / S | 선택 차량 전진 / 후진 |
| A / D | 선택 차량 좌회전 / 우회전 |
| Z / C | 선택 차량 왼쪽 / 오른쪽 평행 이동 |
| Q / E | 포크 하강 / 상승 |
| Space 누름 | 제동 |
| Shift 누름 + 수동 주행 | 센서 조건을 만족할 때 저속 크리프 요청. 자동 작업 중에는 적용하지 않음 |
| Tab | 다음 차량 선택하고 차량 추적·수동 조작 화면으로 전환 |
| End | 선택 차량 추적·수동 조작 화면으로 복귀 |
| G | 정지·무적재 등 조건을 만족하면 다음 사용 가능한 팔레트 선택 |
| PageDown / PageUp | 새 작업의 랙 하역 목표 1단 / 2단 선택 |
| Enter | 선택 차량·현재 팔레트 작업을 중앙 큐에 등록 |
| F | 현재 차량들의 목표 팔레트를 묶어 작업 등록. 차량 수는 현재 3~6대 설정을 따름 |
| Backspace | 선택 차량의 작업 정지 |
| ] | 건강·정차·위치·경로를 재검사하고 명시적으로 작업 재개 |
| 0 | 선택 작업 취소/복구 유지. 적재·고장 상태에서는 예약을 유지하고 수동 복구 필요 |
| X | 선택 차량 비상정지 요청 |
| Y | 정지 후 센서·구동·승강 고장 확인 요청. 원인이 남아 있으면 해제되지 않음 |
| F5 / F6 / F7 | 목표 1 / 2 / 4배 |
| 1 / Home | 전체 조감 자유 카메라 |
| 2 | 외부 주차장 자유 카메라 |
| 3 | 창고 내부 자유 카메라 |
| 4 | 정비/서비스 구역 자유 카메라 |
| H | 지붕 표시 전환 |
| I | 선택 차량 LiDAR 광선 표시 전환 |
| L | 선택 차량 포크 근거리·존재 센서 광선 표시 전환 |
| P | 선택 차량 카메라 촬영·표시 켜기/끄기 |
| O | 선택 차량 후방 영상 RGB / 깊이 전환 |

숫자 0~4는 상단 숫자키입니다. 창고에는 R 리셋·U 고장 주입·5~9 로컬 작업 단축키를 연결하지 않았습니다. 새 세션은 Play를 종료하고 다시 시작합니다. 자동 작업 중 수동 주행·승강·제동 입력은 작업을 정지시킵니다. P로 인식용 촬영을 끄면 자동 작업에 필요한 데이터가 끊길 수 있습니다.

### 창고 자유 카메라

1~4/Home으로 자유 카메라에 들어가면 아래 키가 카메라를 움직이고 차량 수동 입력은 꺼집니다. 자동 운반은 계속됩니다. End 또는 Tab으로 차량 조작 화면에 돌아옵니다.

| 키 | 동작 |
|---|---|
| 마우스 이동 | 시선 회전 |
| W/S 또는 ↑/↓ | 전후 이동 |
| A/D | 좌우 이동 |
| Space 또는 E | 상승 |
| 왼쪽 Ctrl 또는 C/Q | 하강 |
| ←/→ | 좌우 시선 회전 |
| 왼쪽 Shift | 자유 카메라 빠른 이동 |

## 기존 단일 장비 시험장 — Start.bat -Map lab

공통 조작은 W/S 전후, A/D 회전, Z/C 횡이동, Q/E 승강, Space 제동, Shift 수동 크리프, F5/F6/F7 목표 배속, X 비상정지, Y 고장 확인, I/L 광선, P 카메라 촬영·표시, O 후방 RGB/깊이입니다.

| 키 | 시험장 전용 동작 |
|---|---|
| R | 장비·시험 상태 리셋 |
| 1 / 2 또는 숫자패드 1 / 2 | 타이어 마찰계수 감소 / 증가. 길게 누르면 반복 |
| 3 / 4 또는 숫자패드 3 / 4 | 노면 마찰계수 감소 / 증가. 길게 누르면 반복 |
| F | 노면 마찰 기본/저마찰 프리셋 전환 |
| G | 정상/고중심 급조향 스트레스 시험 전환 및 리셋 |
| T | 평지·경사·전체 턱·한쪽 턱·좌우 분할 마찰 등 노면 프리셋 순환 |
| N | 중립 전환 |
| B | 구름·베어링 등 저항 계산 활성 전환 |
| H | 바퀴 하중·저항 상세 표시 전환 |
| M | 구동·조향 모터 상세 표시 전환 |
| J | 타이어 상세 표시 전환 |
| K | 유압 상세 표시 전환 |
| U | 엔코더·높이/리미트·동역학·근거리·LiDAR의 통신 고장 주입/복구. 카메라 촬영 토글과 구분 |
| 5 | 가까운 바닥 팔레트 자동 인양 |
| 6 / 7 | 가까운 랙 1단 / 2단 팔레트 자동 인양 |
| 8 / 9 | 가까운 랙 1단 / 2단 자동 하역 |
| 0 | 로컬 자동 작업 또는 운반 임무 취소 |
| PageDown / PageUp | 새 운반 임무의 랙 목표 1단 / 2단 선택 |
| Enter | 등록된 단일 차량 운반 임무 시작 |
| Backspace / ] | 임무 정지 / 명시적 재개 |
| V | 일반 관찰 / 상단 내부 검사 시점 전환 |
| 마우스 왼쪽·오른쪽 버튼 드래그 | 관찰 카메라 회전. 상단 검사 시점 제외 |
| 마우스 가운데 버튼 드래그 | 관찰 카메라 평행 이동 |
| 휠 위 / 아래 | 확대 / 축소 |
| Home | 관찰 카메라 초기 위치 |

모듈과 장비 구조가 해당 기능을 지원할 때 동작합니다. 예를 들어 메카넘은 고정 방향 휠이므로 기존 조향 모터 표시 항목 중 적용되지 않는 값이 있습니다. 창고의 F/G/H/1~4와 시험장의 같은 키를 혼동하지 마세요.

루트 실행기는 계속 Start.bat이며 옛 모드는 선택 옵션입니다. 아래 키는 기본 창고 조작이 아닙니다.

| 실행 모드 | 키와 동작 |
|---|---|
| Start.bat -Mode drive | W/S 주행, A/D 조향, Space 제동, R 리셋, F 마찰 순환, M 질량 순환, T 토크 순환, C 카메라 전환 |
| Start.bat -Mode lift | Space 자동 승강 사이클, R 리셋, M 적재 질량 순환, F 마찰 순환, T 구동 힘 순환, X 센서 고장 주입, C 카메라 전환 |

## 에디터에서 자주 쓰는 키

에디터 기본 설정에서는 Esc가 Play 종료, Shift+F1이 게임의 마우스 포커스 해제입니다. 프로젝트 자체 단축키가 아니라 Unreal Editor 설정에 따르며, 웹을 조작한 뒤 차량 키를 사용하려면 게임 화면을 다시 클릭합니다.

## 검증 기록

키 배치는 WarehouseCampus.cpp, StabilityLab.cpp, SimulationPlayback.cpp, WheelLab.cpp, ForkliftLabGameMode.cpp와 Unreal의 DefaultPawn 키 정의를 대조했습니다. 단위 110개와 실제 창고의 1/2/4배·주행 중 키 바인딩 전환·자연 시간 시험을 확인했습니다. 실제 마우스/키보드 UI 조작과 웹 시각 배치 검증은 별도로 완료했다고 주장하지 않습니다.
