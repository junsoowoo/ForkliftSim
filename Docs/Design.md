# 무인 지게차 설계 기준

## 목표와 사용자 조건

- 1인 개발, 게임공학/Unreal 경험, 기계 동역학과 ROS 2는 입문 단계
- Unreal 5.6.1, Ryzen 5 5600H / RTX 3050 Laptop 4 GB / RAM 16 GB
- 항만 관제 규모를 반복하지 않고 지게차 한 기종의 물리·센서·제어에 집중
- 최종 작업: 팔레트 탐지 → 접근 → 정렬 → 삽입 → 적재 확인 → 인양 → 운반 → 하역
- 소형 시험장, 규격 팔레트 한 종류, 바닥의 입고·하역 지점 두 곳에서 시작

## 모델의 경계

센서 측정과 제어 명령은 물리 상태와 분리한다. 시험에서는 실제 좌표를 평가에 사용할 수 있지만
최종 팔레트 인식·정렬 제어기는 Actor의 정답 위치를 직접 읽지 않는다. 측정값에는 시각과
유효 여부를 포함한다. 목표 속도·가속도 제한과 실제 동역학 결과를 구분한다.

| 영역 | 모델 변수 | 현재 상태 |
|---|---|---|
| 승강 | 캐리지 질량, 인양력, 이동 범위, 속도·가속도 명령 제한 | 구현 |
| 승강 가이드 | 부호가 부드럽게 변하는 쿨롱 저항 + 점성 감쇠 | 구현, 저속 근사 |
| 적재물 | 팔레트+화물 총 질량, 충돌 형상, 접촉 마찰 | 구현, 질량 분포는 근사 |
| 높이 센서 | 주기, 양자화, 지연, 갱신 중단, 유효 시간 | 구현 |
| 마스트 기울임 | 질량·관성, 회전축, 토크·속도·각도 제한 | 예정 |
| 바퀴 | 반지름, 폭, 회전관성, 구동 토크·속도 한계 | 예정 |
| 제동·접지 | 제동 토크, 바퀴/바닥 마찰, 구름저항, 슬립 | 예정 |
| 차체 | 질량, 무게중심, 관성, 축간거리, 윤거, 조향축 | 예정 |
| 거리 센서 | 장착 위치, 시야각, 거리·해상도, 지연·누락 | 예정 |
| 자율 작업 | 인식, 정렬, 삽입, 운반·하역, 실패 복구 | 예정 |

## SI 단위

설정·계산·CSV는 m, s, kg, N, N·m를 사용한다. Unreal의 cm 기반 물리 API 경계에서만 변환한다.

- 위치·속도: m → cm는 ×100
- 힘: N → kg·cm/s²는 ×100
- 토크: N·m → kg·cm²/s²는 ×10,000
- 중력: 9.81 m/s², Unreal 설정 -981 cm/s²

## 0.1 승강 모델

고정 마스트가 XY 이동과 회전을 제한하고 Z 방향에 1 m 스트로크를 허용한다.
캐리지는 100 kg, 팔레트는 25 kg, 기본 화물은 250 kg이다. 모두 임시 설계 가정이다.
0.65 m 상승 후 2초 유지하고 원점으로 하강한다. 처음에는 포크가 팔레트 삽입구 안에 미리 놓여 있다.

상향 축에 적용하는 순힘은 `액추에이터 힘 - 가이드 저항`이다. 중력과 접촉은 Chaos가 계산한다.
가이드 저항은 `Fc * clamp(v/0.01, -1, 1) + c*v`이며 정지 마찰의 정확한 stick-slip 모델은 아니다.
단동 승강 근사로 구동력은 0..최대 인양력 범위이다. 하강은 중력과 제어된 상향 힘의 균형으로 만든다.

제어기는 위치 오차를 속도 목표로 변환하고 명령 가속도를 제한한다. 속도 PI가 인양력을 출력하고
캐리지 자체 중력만 보상한다. 팔레트의 실제 질량은 이 제어 경로에 넣지 않는다.
실제 가속도는 물리 시뮬레이션 결과라서 접촉 순간 명령 가속도 제한보다 클 수 있다.

높이는 20 Hz, 1 mm 분해능, 50 ms 지연으로 전달한다. 속도 채널은 이상적인 속도 측정에
같은 샘플링·지연을 적용한 첫 모델이며 엔코더 차분/노이즈 모델은 아직 없다.
0.3초 이상 오래된 센서는 고장 처리한다. 힘 포화와 이동 정체가 2초 지속돼도 고장 처리한다.
고장 시 캐리지를 고정하는 이상적인 잠금으로 표현하며 실제 브레이크 성능을 검증하지 않는다.

## 검증 계획

- 같은 설정에서 시간 간격을 줄였을 때 높이·접촉 결과가 얼마나 달라지는지 확인
- 공차·적재·인양력 부족, 상승·정지 유지·하강, 접촉 마찰 변경
- 센서 지연·갱신 중단, 재시작과 반복 사이클
- 실제 하중 질량과 바디 질량 중복 가산 여부 확인
- 주행 단계에서 제동거리·회전반경·슬립, 적재물 미끄러짐 검증
- 팔레트 인식 단계에서 위치·각도 변화별 정렬 오차와 성공/실패율 기록

제조사 공개 사양, 설계 가정, 실험 보정 값을 구분한다. 실물 데이터가 없으면 실물 정합성 검증으로
표현하지 않는다. 시험 로그에 설치 엔진 버전과 모델 설정을 함께 보관한다.
