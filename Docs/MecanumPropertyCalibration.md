## 공개 자료와 현재 모델의 차이

제조사 [Hickwall HIT305AHD 제품 표](https://www.hit1994.com/en-US/p104-12-in-mecanum-wheel)는 지름 305 mm, 폭 156 mm, 질량 40 kg, 롤러 8개, PU 롤러·주철 프레임, 표기 하중 3,000 kg을 제시한다. 2026-10-29 확인. 현재 300 mm, 폭 160 mm, 50 kg, 롤러 12개의 가상 휠과 **다른 제품**이다. 공개 표에 시험 속도·충격·피로·듀티 조건이 없어 이를 검증된 동하중 한계로 취급하지 않는다.

`Config/Mecanum.json`의 `catalogue_comparison`은 **비교용 메타데이터**다. 현재 질량·관성·마찰·롤러 형상을 해당 제품 사양으로 바꾸거나 현재 휠에 정격을 부여하지 않는다. 제조사 표의 총질량만으로 허브·롤러 질량 배분이나 관성 텐서를 복원할 수 없다. 롤러를 8개로 줄이면 접촉 형상과 연속성이 바뀌므로 별도 형상 제작과 재검증이 필요하다.

제조사 [SKF의 마찰 모델 설명](https://evolution.skf.com/using-a-friction-model-as-an-engineering-tool-3/)은 구름·미끄럼·씰·윤활 저항을 구별하고 하중·속도·윤활 조건을 사용한다. 현재 `.03 Nm + .002 Nms × 속도`를 SKF 실측값으로 표기하지 않는다. [Blickle PU 안내](https://www.blickle.us/en-us/guide/polyurethane-wheels)도 서로 다른 PU 재료 특성을 구별한다. 기존 Blickle 일반 휠 정격은 메카넘의 정격으로 이월하지 않는다.

제조사 다운로드에서 **HIT305AHD-A PDF, DWG, STEP** 원본을 추가 확보했다. `Docs/References/MecanumSources-20261029/manifest.json`에 URL·원본 해시를 기록한다. PDF 전체 페이지를 렌더링해 확인했으며 도면 외경 304.90 mm는 웹 표의 반올림 305 mm와 구별한다. 폭은 도면도 156.00 mm다. 도면에 관성 텐서·마찰 곡선·정격 시험 속도는 없다. STEP는 원본 형상 자료로 보관하며 현재 가상 휠을 해당 CAD로 교체한 것으로 표기하지 않는다. Blickle 웹 자료는 브라우징으로 확인했으나 직접 원문 보관은 TLS 검증 실패를 기록했다.

## 실제 하중과 비교

`Scripts/audit_mecanum_properties.py`는 이전에 완료된 28개 native 시험의 CSV SHA-256을 확인하고, 시작 1초 뒤 바퀴별 **프레임 평균 하중 최대값**을 정리한다. 원본은 `Docs/References/MecanumConservation-20261029.json`이며 결과는 `Docs/References/MecanumPropertyAudit-20261029.json`이다.

가장 큰 평균 하중은 한쪽 턱 시험의 FL 27,045 N이며 비교 제품의 표기 하중×9.81에 대한 비는 약 91.9%다. 이는 충격 피크·피로·정격 적합성 판정이 아니다. 공차 하중을 단순히 4로 나누면 이런 편중을 놓친다. 이전 메카넘 CSV의 `integrated_inner_peak_wheel_n=0`은 해당 계측 분기가 실행되지 않은 값이므로 **미측정(null)**으로 처리한다.

웹에는 Unreal이 보낸 현재 바퀴 질량·하중 비교 비율·비교 제품명이 표시된다. 비교 비율은 참고 제품과의 수치 비교이며, `rated_load_qualified=false`를 유지한다. 실제 보정은 `measured_calibration_complete=false`다.

## 실측 자료를 받았을 때의 식별 순서

1. 무적재/적재 정하중으로 부품 질량·무게중심을 확인한다.
2. 분리 휠의 질량·관성을 확인한 후 무동력 회전 감쇠로 베어링 저항을 식별한다.
3. 평지 중립 감속을 비교해 구름저항을 확인한다. 모터·브레이크 상태를 별도로 기록한다.
4. 견인/제동 시험으로 바닥 쌍의 마찰을 식별한다. 마찰과 구름저항을 하나의 계수로 맞추지 않는다.
5. 토크–속도·양중·포크 하중 시험을 독립 검증 자료로 남긴다. 식별 자료와 검증 자료를 구분한다.

지금까지의 시뮬레이터 자체 시험을 실제 장비 시험 데이터로 취급하거나, 그 결과에 맞춰 가정값을 조정한 것을 실측 보정으로 표현하지 않는다.

## 3번 병행: 체인 손실 계측

기존 인장 전용 힘 `T=max(0,k·x+c·v)`는 유지한다. 회수 가능 에너지는 `U=0.5·k·max(x,0)^2`, 구성식 손실 전력은 `(T−k·max(x,0))·v`다. 장력이 0으로 잘린 급격한 이완 구간에서는 `c·v²`를 그대로 더하면 손실을 과대계상한다. 이 구간을 포함해 독립 에너지 미분과 비교한다.

체인 손실은 유압유 발열과 분리하여 `energy_chain_damping_j` 및 실시간 `energy_audit.chain_damping_j`로 전달한다. 바퀴 구름저항·롤러 베어링·제동 소산과 중복 합산하지 않는다. 포크 감쇠·소성, 접촉 마찰·충격, 잔여 수치 손실은 여전히 전체 잔차에 포함된다. **전체 에너지 폐합 완료로 바꾸지 않는다.**


## 이번 최종 빌드 검증

- Unreal 빌드 성공. 전체 단위 시험 **32/32**, 선택한 native 회귀 **5/5** 통과: 중립, 공중 회전 보존, 적재 경사 제동, 적재 한쪽 턱, 높은 위치 운반.
- 새 체인 구성식은 인장·급격한 이완·음의 신장 조건의 에너지 미분과 비교했다. 힘 법칙과 기존 주행 설정은 유지했다.
- 최종 실제 높은 위치 운반의 웹 600표본과 **192열 CSV 데이터 생성 함수**를 검증했다. 브라우저 다운로드 자체를 자동 조작한 시험은 아니다. 웹 회귀 5개 통과.

### 새로 확인한 충격 하중과 기록 해상도의 차이

별도 실제 웹 수신 기록 6,221표본에서 한쪽 턱의 **프레임 평균 하중 최대 47,073.8 N**, 해당 프레임들 내부의 **물리 스텝 최대 96,030.3 N**을 관찰했다. 이전 28개 CSV의 27,045.2 N은 낮은 기록 빈도에서 잡힌 최대값이며 모든 프레임의 최대값을 뜻하지 않는다. 연속 수신도 누락 프레임을 재구성하지 않으므로 이번 값 역시 관찰한 표본의 최대값이다.

96 kN은 현재 강체 롤러·강체 턱·1/1920 s 계산의 충격 피크다. PU 실제 압축과 접촉 지속시간, 계산 간격별 충격력 수렴이 검증되지 않았다. 제조사 표기 하중과 단순 비교해 현재 휠이 적합하거나 실제 휠이 파손된다고 판정하지 않는다. **평균 정하중만 보고 휠 정격이 충분하다고 결론내릴 수 없다는 것을 확인한 것**이다. 가정한 마찰·강성을 조절해서 충격 피크를 표기 정격 이하로 맞추지 않았다.
