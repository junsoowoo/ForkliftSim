# 물리 상세화 작업 묶음

이후 승강 제어 연결은 [SensorLiftControl.md](SensorLiftControl.md)를 따른다. 높이·리미트·실린더 압력을 기본 integrated의 높이 제어/승강 제한에 연결했다. 나머지 센서의 자동 제어·팔레트 인식·삽입 판정·자율 주행은 후속이며 아래 당시 미연결 설명과 시험 수치는 이력이다.

이후 근거리 센서 묶음은 [ProximitySensors.md](ProximitySensors.md)를 따른다. 기본 integrated에 포크 전방 거리 4개·위쪽 물체 감지 4개를 추가했으며 아래 당시 미구현 설명·시험 수치는 이력이다.

2026-11-05 이후 묶음: [DynamicsSensors.md](DynamicsSensors.md). IMU·실린더 압력·좌우 포크 접촉 하중의 별도 측정 출력을 추가했다. 아래의 당시 미구현 설명과 검증 수치는 이력이며, 새 센서의 검증은 해당 문서를 따른다.

이후 관절 센서 첫 묶음은 [JointSensors.md](JointSensors.md)를 따른다. 엔코더·높이·리미트 측정 모델을 기본 integrated에 추가했고, 센서 기반 자동 제어는 아직 연결하지 않았다.

2026-10-31 현재: 사용자 지정 우선 작업 **두 단 랙·현재 차체 통합 시험·수치 오차·공개 사양 대조**는 [CurrentPhysicsQualification.md](CurrentPhysicsQualification.md)를 따른다. 기본 경량 메카넘은 960Hz·32/32회이며 아래 1920Hz 이력은 정밀 모델 기록이다. 이번 범위에는 새 센서·자동화·정밀 재료 해석 확장을 포함하지 않는다. 실측 보정과 전체 에너지 폐합은 여전히 별도다.

2026-10-29 추가: 최근 메카넘 목록의 **5번(물성 근거 정리·보정)**과 **3번(에너지 손실 분리)**은 [MecanumPropertyCalibration.md](MecanumPropertyCalibration.md)를 따른다. 아래 일반 타이어 시절의 5번과 번호의 의미가 다르다. 공개 정격의 가상 휠 전용은 하지 않으며 실측 보정·전체 폐합은 미완료다.

**최신 0.18:** 관절 보존·중립 감속·브레이크 기준각 수정, 메카넘 28/28·단위 31/31 통과. 기본 1920Hz·32/32회. 전체 손실 수지·실측 보정은 별도다. [현재 결과와 한계](MecanumConservation.md). 아래 표의 이전 미통과 항목은 해당 버전 당시의 기록이다.

각 묶음은 구현 → 같은 조건의 비교 시험 → 기록·한계 정리 순으로 마무리한다. 현재 구현은 시험용 강체 모델이며 아래 작업이 끝나도 실차 보정은 별도다.

현재 기본 실행은 **메카넘 휠**이다. 이전 일반 타이어·연결 링의 시험 결과와 미완료 기준은 이력으로 유지하며 새 모델과 구별한다.

## A의 구현 범위

- 기본 cargo_secured=false. true는 이상적인 고정 관절을 쓰는 비교 조건이며 실제 스트랩의 장력·파단 모델은 아니다.
- 팔레트 상판과 화물 바닥에 각각 정지·운동 마찰계수를 지정한다. 실제 접촉력은 Chaos가 계산한다.
- 화물의 팔레트 대비 이동량·접촉 미끄럼 속도·상대 기울기·하단면 겹침을 기록한다.
- 팔레트가 화물에 가한 힘과 접선력, 화물의 바닥 접촉, 다른 물체 접촉을 구분한다.
- 포크–팔레트 기록, 바퀴별 접촉 하중·저항은 유지한다. 화물 낙하 후에는 팔레트에서 빠진 무게가 바퀴 하중에도 반영되어야 한다.
- 화물 강체는 하나의 직육면체다. 상자 다층 적층, 포장재 변형·파손, 실제 고정 벨트는 후속 범위다.

세부 조작·시험 설명은 [CargoContact.md](CargoContact.md)를 참고한다.

- 조향 명령 지연과 출력축 유격, 힘 제한 관절의 가용 토크, 실제 조향 관절·노면 반력 계측.
- 고정 6도 경사로·25 mm 턱·동일 높이의 좌우 분할 마찰, 노면 전환 시 강체·계측 초기화.
- 모터 출력별 가속/등판, 마찰별 미끄럼 비교. 기존 화물 접촉·운반 회귀 유지.

## C1의 구현 범위

- 강성·감쇠·이동 한계 설정, 실제 상대 변위·관절 전달력·내부 스텝 감쇠 일과 바퀴별 하중을 기록한다.
- 휠 중심–노면 하중 반경과 v/omega 관측 구름반경을 구분한다. 원형 강체 접촉 링의 구름반경을 눌림량만큼 임의로 줄이지 않는다.
- 30/60 FPS의 강성·감쇠·턱 A/B, 비고정 화물 양중, 1/240·1/480초 내부 물리 간격 비교를 수행한다. 작은 저항의 수치적 분해를 위해 기본값은 1/480초로 올렸으며 연산량이 늘어난다.
- 실제 고무 형상·면압·단차 감싸기·횡탄성·하중별 구름반경 변화는 미구현이다. 충격 피크와 소산 에너지의 계산 간격 민감도도 남아 있다.
