## 1. 질량·형상·물성의 연결

포크 날은 동일 단면 직육면체로 근사한다. 강철 밀도 7,850 kg/m³라는 설계 가정에서 날 하나의 질량은 56.52 kg이다. 날 2개 113.04 kg + 캐리지 80 kg + 이동 마스트 30 kg = 승강부 223.04 kg으로 배분한다. 바퀴·모듈의 기존 가정 질량과 합쳐 차체 잔여 질량을 2,696.96 kg으로 설정해 총 3,140 kg을 유지한다. 부품별 질량·COM·관성은 실제 장비에서 추출한 데이터가 아니다.

작은 바퀴로 바뀌어도 포크가 바닥 아래에서 시작하지 않도록 지면 기준 삽입 높이를 분리했다. 팔레트 생성 위치·삽입 겹침은 실제 포크 끝과 뒤꿈치 위치에서 계산한다. 포크 분할 후에도 모든 구간의 질량·접촉력을 합산하며 바퀴 하중으로 전달한다.

## 2. 타이어

기존 수직 스프링·댐퍼에 전후·좌우 전단 탄성·감쇠를 더했다. 비회전 지지부와 접촉 링 사이의 실제 Chaos 관절에서 힘을 전달한다. 노면 반력이나 마찰력을 별도 AddForce로 중복 적용하지 않는다.

수직 탄성은 `F=kδ+k3δ³`, 저장 에너지는 `E=kδ²/2+k3δ⁴/4`다. 접선 강성으로 관절을 선형화하고 평형 위치를 옮겨 비선형 힘을 근사한다. 전단 스프링의 저장 에너지도 포함한다. 계수는 가정값이며 경도만으로 하중–변형 곡선을 측정한 것처럼 만들지 않는다.

눌림으로부터 추정 접촉 길이 `2√(2Rδ−δ²)`와 반타원 압력 분포의 추정 최대 면압 `4N/(π·폭·길이)`를 제공한다. **추정 패치와 면압은 실제 솔버의 접촉 압력 분포가 아니다.** 링은 강체이고, 실제 고무의 3차원 변형·턱을 감싸는 접촉·고무 유한요소 해석은 아직 포함하지 않는다. 이 모델은 3축 구성식의 축약 모델이다.

## 3. 포크의 휨·영구변형·연결 파손

각 날을 4개의 독립 강체 구간으로 나누고 회전 탄성·감쇠 관절로 연결한다. 모든 구간이 팔레트와 충돌해 실제 힘을 전달한다. 단면 2차 모멘트는 `I=b·t³/12`, 구간 관절 강성은 `EI/구간길이`, 고정단의 반구간 강성은 그 2배다. 끝단 집중하중의 Euler–Bernoulli 해와 비교하면 4구간 모델의 이산화 오차는 약 3.125%다. 실제 단면 테이퍼·굽은 뒤꿈치 형상·비틀림은 재현하지 않는다.

항복 후에는 관절의 평형 각도를 이동시켜 소성 굽힘을 남긴다. 등방 경화를 갖는 1차원 return mapping으로 누적 소성 변형에 따른 항복 한계 변화를 계산한다. 과도한 탄성 시행 응력 또는 누적 소성 회전 시 실제 관절 연결을 해제한다. **탄성계수 210 GPa, 파단 응력 1,100 MPa, 파단 소성 회전 10°, 경화비 0.05와 감쇠는 설계 가정**이다. 피로 수명·균열 전파나 실제 포크의 파단 하중을 예측한 것으로 사용할 수 없다. 응력 표시는 관절 변형에서 추정한 최대 탄성 시행 응력이며 측정 스트레인 게이지가 아니다.

## 4. 이동 마스트·체인·유압

차체·이동 마스트·캐리지를 별도 강체로 둔다. 실린더는 실제 이동 마스트에 힘을 가하고, 체인 신장과 장력으로 캐리지를 올린다. 선택한 이상화 로프 경로는 속도비 2:1이다. 캐리지에 +T, 이동 풀리에 −2T, 차체 고정점에 +T를 가해 내부 힘의 합이 0이 되도록 한다. 실린더 반력도 차체에 적용한다. 마스트는 한 이동단과 캐리지로 구성한 2단 축약 모델이며 실제 제품의 모든 마스트 옵션을 재현하지 않는다.

체인은 인장만 전달하는 스프링·댐퍼다. 이동 마스트 질량·배율·강성·감쇠는 식별되지 않은 설계값이다. 적재 상태에서 체인 신장 때문에 캐리지 높이가 이동단 높이의 정확한 2배보다 작을 수 있다. 자동으로 높이를 보상하거나 화물을 붙여 놓지 않는다.

배관은 4개의 유체 관성과 5개의 압력 절점으로 구분한다. 압축성·점성 손실과 압력파의 이동·반사를 계산하며 CFL 기준으로 유압 내부를 추가 분할한다. 실린더 압력과 펌프측 압력을 분리한다. 파속은 유효 체적탄성률과 밀도에서 구하고, 실제 호스 변형은 유효 탄성률에 포함한 가정이다. 호스 길이·내경·체적, 밸브·펌프 곡선은 OEM 자료로 보정되지 않았다.

오일 온도는 손실열과 외기 방열로 변한다. 공개된 40/100°C 동점도로 보간한 점도가 배관 저항·누설·점성 씰 저항에 영향을 준다. 밀도는 일정 근사이고 열용량·방열계수는 가정이다. 음의 게이지 압력에 도달하면 모델 범위 경고를 남긴다. 2상 공동화나 3차원 유동 CFD는 계산하지 않는다.

## 실행·계측·검증

사용자 실행은 기존 **Start.bat** 하나다. 최신 통합 프로필에 위 기능이 포함된다. 기존 가상 기준 V1의 회귀는 `-ReferencePhysics`와 C++ 기본 사양으로 분리해 유지한다.

웹에는 포크 끝 처짐·최대 굽힘 응력·잔류 힌지각·연결 파손, 이동 마스트 높이·체인 장력/신장, 오일 온도/점도, 펌프·실린더·배관 압력과 점성 손실을 전송한다. 타이어 전단 변형과 추정 패치/면압도 원본 JSON에 포함한다. 기존 바퀴·포크·화물 하중 및 마찰 계측을 유지한다.

```powershell
.\Scripts\Test-Components.ps1
.\Scripts\Test-Components.ps1 -Fps 30 -Cases lift,ramp_brake
```

양중·운반·하강·경사 정지 유지와 고정단 파손 벤치를 구분한다. 파손 벤치는 차체와 캐리지를 명시적으로 고정한 파괴 시험이며 일반 주행 상태의 정격 시험이 아니다. 실행별 소스/설정 해시와 결과를 `Saved/Validation/Components-*`에 보관한다. 수치 기준 통과는 실제 장비 보정이나 인증을 의미하지 않는다.
